# GoalPath – مسار الإنجاز الذكي | Full-Stack Application

تطبيق متكامل مبني بالاعتماد على كافة تصاميم وهوية **GoalPath** (الملفات الأصلية المحفوظة في المجلد من `lavender_1` إلى `lavender_11` و `ai_lavender` و `goalpath_lavender/DESIGN.md`) مع بناء **Backend (REST API)** متكامل وقاعدة بيانات SQLite تفاعلية وواجهة أمامية تربط كافة العمليات بنجاح.

---

## 🚀 كيفية تشغيل المشروع (How to Run)

لتشغيل المشروع، يمكنك تنفيذ الأمر التالي في موجه الأوامر (Terminal/PowerShell):

```bash
python start.py
```

سيتم تشغيل الخادم وفتح الواجهة تلقائياً على الرابط:
👉 **`http://127.0.0.1:5000`**

## 🌟 الشاشات والوظائف المربوطة بالـ Backend

1. **شاشة الترحيب (Welcome / Splash - `lavender_1`)**: استعراض واجهة البداية وهوية مسار الإنجاز الذكي.
2. **لوحة التحكم (Dashboard - `lavender_2`)**: إحصائيات حية، نسبة الإنجاز العامة، بطاقات الأهداف النشطة المحسوبة ديناميكياً من قاعدة البيانات.
3. **التسجيل والدخول (Auth - `lavender_3`)**: إنشاء حساب وتسجيل دخول متصل بقاعدة البيانات.
4. **إنشاء هدف جديد - الخطوة 1 (`lavender_4`)**: تحديد اسم الهدف، التصنيف، التواريخ، والأولوية.
5. **توليد الخطة الذكية - الخطوة 2 (`ai_lavender`)**: يقوم الذكاء الاصطناعي بتوليد مراحل ومهام مخصصة لكل هدف مع إمكانية اعتمادها وحفظها في قاعدة البيانات بضغطة زر.
6. **تفاصيل ومسار الهدف (`lavender_5`)**: دائرة التقدم الحية ومخطط زمني للمراحل والمهام مع إمكانية إنجاز المهام فورياً.
7. **المساعد الذكي وحلول التعثر (`lavender_6`)**: تشخيص سبب التأخر (ضيق الوقت، الصعوبة، فقدان الحماس، الأولويات) وتقديم خطة إنقاذ وإعادة جدولة قابلة للتطبيق الفوري.
8. **الخطوة القادمة الفورية (`lavender_7`)**: تركيز على المهمة القادمة مع مؤقت زمني لجلسة التركيز.
9. **تقارير الإنجاز والتحليلات (`lavender_8`)**: رسوم بيانية أسبوعية ونسب إنجاز مفصلة.
10. **مهام اليوم (`lavender_9`)**: قائمة تفاعلية لمهام اليوم مع خيارات التصفية والإضافة السريعة ومزامنة التقدم.
11. **الملف الشخصي والإعدادات (`lavender_10`)**: تفعيل الوضع الليلي، الإشعارات، ومعلومات المستخدم.
12. **الإنجازات والتحفيز (`lavender_11`)**: نظام النقاط، الشارات، وسلسلة الأيام (Streak) مع مكافآت فورية عند إكمال المهام.

## 📡 مسارات الـ REST API (Endpoints)

- `GET /api/dashboard`: ملخص البيانات والإحصائيات والهدف القادم.
- `GET /api/goals` & `POST /api/goals`: جلب وإنشاء الأهداف ومراحلها.
- `GET /api/goals/<id>` & `DELETE /api/goals/<id>`: إدارة هدف وتفاصيله.
- `GET /api/tasks` & `POST /api/tasks`: إدارة المهام اليومية والجديدة.
- `POST /api/tasks/<id>/toggle`: إكمال/إلغاء إكمال المهمة وتحديث النقاط ونسبة الهدف فورياً.
- `POST /api/ai/generate-plan`: محرك الذكاء الاصطناعي لتوليد المراحل والمهام.
- `POST /api/ai/diagnose-stumble`: تحليل سبب التعثر وتقديم نصائح الإنقاذ.
- `POST /api/ai/apply-solution`: تطبيق الحل الذكي وتحديث مواعيد ومهام الخطة في قاعدة البيانات.
- `GET /api/reports`: إحصائيات الأداء وتوزيع الأيام والتصنيفات.
- `GET /api/achievements`: قائمة الشارات المكتسبة والمغلقة ورصيد النقاط.
- `GET /api/auth/user` & `PUT /api/auth/user`: إدارة الملف الشخصي والإعدادات (الوضع الليلي والإشعارات).
